# Meus Estudos
Este repositório reúne meus estudos práticos em programação, com foco em Python.
Aqui registro exercícios, testes, anotações e pequenos projetos desenvolvidos ao longo da minha jornada de aprendizado.
A ideia não é ter códigos "perfeitos", mas sim mostrar evolução, raciocínio lógico e aplicação prática dos conceitos aprendidos.

# Tecnologias e Ferramentas
- Python

# Conceitos e Práticas
- Programação Orientada a Objetos (POO)
- Estruturas de controle e dados
- Organização de projetos
- Desenvolvimento de APIs
